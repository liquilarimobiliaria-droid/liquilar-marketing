# liquilar-marketing

Artes e mídia de marketing da LiquiLar | Liquidez Imobiliária (CRECI/MS 16939-J).

Este repositório é público. Ele serve para hospedar arquivos que já vão ser publicados nas redes e que o Metricool precisa buscar por link.

Regras:
- Só entram artes e vídeos já aprovados para publicação.
- Nunca colocar contratos, dados de clientes, feeds, chaves, senhas ou endereço de imóvel.

Pastas:
- instagram/artes: artes de posts, nomeadas como AAAA-MM-DD_assunto
- youtube: banners e miniaturas
- liquinews-logos: logos do LiquiNEWS
